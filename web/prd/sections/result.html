What the model says

  1. The grid binds before the budget does. The start preset spends $23.6B of the $30B budget and still serves only 32% of peak demand, because the six Earth sites already draw 499 MW. Serving every Case B user on Earth would draw 1,554 MW, about three times the cap.
  2. Decode on LPUs cuts energy per output token by a third. Moving decode to LPU racks takes the fleet from 1.12 J to 0.75 J per output token and lifts the share served from 32% to 48%, inside the same 500 MW.
  3. Orbit nearly closes the serving gap, then the budget binds. Sending the overflow to low Earth orbit adds 499 MW of compute and serves 97% of peak demand, at a five-year cost of $39.7B against the $30B budget. A 40 ms round trip keeps orbit fast enough for chat; the Moon at 2.6 s takes background work only.
  4. The price question has a clean answer. Agent developers would have to pay between $19.66 and $34.45 a month for five years to cover the build, against $20 plans sold today. The break-even price needs no guess about 2035 prices.
  5. Ten years of hardware is the biggest lever. The same demand on 2025 racks needs 27,651 racks, 4,001 MW and $189.7B, at 2.88 J per output token.

The business case at a $20 plan

Year-0 capex is racks, buildings and launches; each year after that earns subscription revenue and pays energy, carbon and maintenance. NPV discounts at 10% a year. Payback counts undiscounted cash.

What it looks like

Renders from RealityHD, Hunter Harris's procedural prop library for the Terawatt visionOS app, MIT licence. The web twin shows the matching render in its level card at the chip, rack and off-world levels.

Limits we know about

  • Vision Pro is tested in emulation only. The session, table placement, picking and the panel buttons for zoom out, lens, year, preset and life size pass under an emulated headset, where the emulator's controller select stands in for a Vision Pro pinch. The panel's recentre button is not tested. Gaze-and-pinch on a real Vision Pro uses the same select event, but nothing has been tried on a device yet.
  • Geometry is schematic. Sizes on the table explain; the numbers in the panels are the data.
  • Sentiment is a sample. One recent local news article per site, with a stance we labelled (source). Two of the seven articles could not be re-fetched for a second check, and the data says so.
  • Water stress is not retrieved. The water check uses a climate rule instead (rule).
  • Prices are 2026 list prices, not 2035 forecasts. The break-even price avoids that guess.
  • Building cost is a choice. The default is $17.6M per MW from a 2026 industry guide; the Terawatt app engine uses $11M. The slider covers both.
  • Cleanview's markers stay local. Its licence does not allow redistribution, so the public build credits the totals, 1,372 operating and 2,689 planned data centers with reported capacity, and links to the map.

Reproduce it

npm test                          # engine and source tests
node scripts/presets-table.mjs    # every preset through the engine, writes test-results/presets.json
npm run presets                   # the same, as an npm script
npm run serve                     # then open http://localhost:8145

# browser checks (need playwright-core and a Chromium)
PLAYWRIGHT_CORE=/path/to/playwright-core CHROME=/path/to/chromium node tests/e2e/smoke.mjs

# XR checks (also need IWER, Meta's Immersive Web Emulation Runtime build)
PLAYWRIGHT_CORE=/path/to/playwright-core CHROME=/path/to/chromium IWER=/path/to/iwer.min.js node tests/e2e/xr.mjs
